# Corrected Style 4 artwork

The user's `style4_corrected_486.zip` supplies corrected artwork for 243 of the
existing 486 Library drawings. The remaining 243 selected entries retain their
previous Style 4 artwork, including the eight recovered earlier drawings that
the corrected package would otherwise replace with older versions. These are
appearance updates to existing biological concepts and illustrative analytical
graphics; the catalog still contains 386 concepts across 11 collections.

The correction is append-only. The original Style 4 SVGs, manifest, supplied
metadata, recovery record, contribution notice and accepted product decision
remain unchanged. A new manifest selects the corrected drawings and retains
their previous variant records. Existing saved drawings keep the source SVG
stored with their documents. Styles 1–3 retain their existing artwork.

The finite correction record binds the supplied archive, all added files, the
new selection manifest and current Library registry. Validation reconstructs
and checks the exact previous inventory and registry before checking the
correction. New or modified artwork therefore cannot inherit an older approval.
The existing repository contribution policy applies; no new personal licensing
attestation is asserted.

The correction is accepted for source inclusion. All 486 supplied SVGs passed
semantic checks and rendered in Chromium (976 checks). An independent reviewer
inspected 216 drawings on 15 original-resolution boards, including all 40
protected analytical templates and the six drawings with empty outline groups.
Those empty wrappers remain in the supplied SVG; their inactive part-color rows
are omitted, while the visible contours remain in their authored regions.
The import passed 22 targeted checks and exact archive reproduction.

A focused check used the existing beta.12 runtime with the corrected artwork
and the part-color compatibility change. At 1440 × 1000 in light appearance,
129 checks passed for four representative drawings in Figure and Presentation,
including selection, switching, palette and part-color edits, original-color
restoration, and three actual Save/cold-Open pairs (`fsfigure`, `fsdeck` and
`fsproject`). An independent reviewer accepted all four original-resolution
populated and cold-opened captures. This is browser-hosted native vector
editing, not qualification of the Windows desktop host.

This source update is unpublished. The selected shared web and desktop package
remains beta.12. No new package, installation, publication or repeated full
