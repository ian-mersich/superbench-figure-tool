# Contributing

Bug reports and focused changes are welcome. Before opening a pull request, describe the user-visible behavior affected and include a focused reproduction or test. Keep persisted `.fsfigure` and `.fsdeck` formats and the host integration interfaces compatible unless a change explicitly updates their versioned contracts.

Run the focused checks listed in `README.md`. If you edit vendored code, preserve its upstream license, update `vendor/NOTICE` and `vendor/manifest.json`, and document the source and patch. Do not add assets unless their distribution rights are documented and compatible with the public release.
